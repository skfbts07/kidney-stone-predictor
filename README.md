# Kidney Stone Detection Using Ultrasound Scans

## About the Project
This project predicts the presence of kidney stones using ultrasound scan images.  
It applies machine learning and image processing techniques to classify whether a scan indicates a kidney stone or not.  
The goal is to assist medical professionals in early detection and diagnosis.

## Tools & Technologies
- Python  
- TensorFlow / Keras  
- OpenCV  
- NumPy  
- Matplotlib  

## Features
- Image preprocessing and enhancement  
- Model training and evaluation  
- Prediction of kidney stone presence  
- Visualization of results
